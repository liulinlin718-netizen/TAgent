# 只读探索、周期任务与执行快照

## 当前状态（2026-09-18）

上轮按用户要求先开发，本轮完成必要本地验证。四包类型检查/lint、AI/Core/Server构建、Web普通与本机独立生产构建通过；全量101文件1487项Vitest和40项脚本自检通过。实际通过情况与仍未证明的范围在文末区分，不引用旧版数量冒充本轮结果。

初心仍是非技术用户可理解、可控制的办公协作。没有新增依赖、后台付费授权、邮箱访问、Desktop、Docker、自动对话合并或无限递归。

## 只读探索

- 对话输入区增加办公协作/只读探索选择。`POST /api/agent/orchestrate` 接受 `mode: "explore"`，继续使用相同的运行准入、取消、SSE、来源检查点与最终保存。
- 单次页面任务执行一个有界公开调研问题，调用现有 `web_research` 读取多个来源，随后最多一次无工具摘要。不注册 MCP、写入工具、Skills脚本或子 Agent 创建工具。
- Core 的 `runExplore` 支持最多3个独立问题、并发最多3，默认2；问题由调用者提供，不让模型无限扩展。页面默认只提交一个问题。
- 保留 Agent 的工具白名单、域名约束、逐次审批和预算。未授权 `web_research` 时不能执行；没有可读相关来源时不靠模型记忆补造答案。
- 对最新/近期问题，没有合格日期来源时只保留背景材料，不调用模型生成“最新”摘要。来源日期、URL、读取状态、相关性和未独立核验说明随结果显示。
- 摘要为初步探索，不代表完整报告逐条核对通过。截断/失败不自动重试，保留材料与已返回草稿。
- 可选 `TAGENT_EXPLORE_MODEL` 使用同一个 Provider/账户；未设置则沿用当前模型，不自动换账户。只有已知模型价格且摘要预算预留足够时才调用摘要。默认模型部分上限0.15美元，与 Agent 自身上限取小；搜索服务可能单独收费，此值不是供应商账单硬上限。

## 运行状态与周期待办

页面：`/management/runtime`。

- `GET /api/runtime` 从同一份 WorkflowCatalog 计算真实保留任务数、失败/未知状态、已知模型费用、Token、工具返回次数和可配对耗时。
- 常驻 Agent 尚未执行时显示“尚未运行”；根据实际事件区分空闲、运行、等待确认和暂未收到新事件。不把静默的空闲 Agent 当成死亡，也不把未知用量当成零账单。
- `GET /api/metrics` 保留主要兼容字段；未实测指标返回 `null`。`GET /api/heartbeat` 改为事件驱动的活动状态，旧的手动 POST 心跳返回409，避免人为制造健康状态。
- 周期任务保存在 `scheduled-tasks`，写入成功后才发布状态。提供创建、编辑、暂停/启用、删除和到期待办；编辑采用版本检查，新建页面请求采用稳定请求标识防止重试重复创建。
- 当前支持固定间隔1分钟至366天、本地日期输入的首次到期时间；**不是完整 Cron 表达式或跨实例调度器**。
- 调度器每15秒检查到期任务，只创建本地待办。离线错过多个周期只合并为一条，已有未处理待办不继续堆积。
- 每次用户点击“打开待发送任务”后才创建空会话并填入草稿，仍需手动发送才调用模型。重复打开复用同一会话；创建会话后待办记录写入失败可重试本地保存，不重复创建或执行。
- 修改任务会取消尚未打开的旧待办；删除任务不删除已准备的对话。最多50个任务、200条处理记录。

接口：`GET/POST /api/cron`、`PUT/DELETE /api/cron/:id`、`POST /api/cron/occurrences/:id/prepare`、`POST /api/cron/occurrences/:id/dismiss`。保存及准备必须显式确认，`execution`固定为`confirm_each_run`。

## 执行快照分支

- 普通 Agent Loop 每轮调用模型前捕获实际消息上下文，带原工作空间、会话、run、Agent、子任务及迭代编号。
- 服务端保存到 `execution-snapshots`；全局最多200条、8MB（按文件JSON格式计算），单条最多512KB。超大快照不截断伪装完整，保存失败给治理提示，但不丢弃最终任务输出。
- 会话顶部“执行快照”可读取列表、展开材料并确认创建分支。列表不带正文，详情隐藏系统提示和原始工具参数。
- 分支只承接该时刻的输入与中间材料，明确标记为历史参考；不复制后来才产生的最终回复，不复制运行许可、不重复归集旧费用、不调用模型。
- 同一来源快照的重复确认返回同一个分支；来源归属校验，删除来源后不再公开遗留快照。
- 这是**上下文参考分支**，不是模型进程恢复、文件系统回滚或工具状态重放。旧任务不补造快照。

接口：`GET /api/workspaces/:wsId/sessions/:sessId/snapshots`（可按runId筛选）、`GET /api/snapshots/:id`、`POST /api/snapshots/:id/fork`（`confirmed=true`）。

- `spawn_agent` 不再天然绕过工具白名单；原有受控计划子 Agent 与手动保存流程保留。
