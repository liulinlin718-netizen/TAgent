# 原始表格分析

更新：2026-09-14。本能力落实实施方案中的数据办公 Agent，不代表六类办公交付或上线验收已完成。

## 用户入口

在首页“数据分析”的材料栏粘贴表格，或直接在对话中提供表格与问题。支持 CSV、从电子表格复制的制表符文本（TSV）、分号分隔 CSV、Markdown 表格。需要明确表头、单位、时间范围和比较基期，不要求用户编写脚本。

例如：

```text
请按月份汇总收入，并比较2月相对1月的变化。收入单位为万元，不联网。
月份,收入
1月,0.1
1月,0.2
2月,0.6
```

内置数据 Agent 具有 `read_data_source` 和 `analyze_table` 权限；其他 Agent 需通过现有编辑流程明确授予。新通用 Skill“原始表格计算”提供执行步骤和质量清单，可在大厅绑定。已保存的用户 Agent/Skill 绑定不被覆盖，绑定 Skill 本身也不增加工具权限。

## 从表格文件准备材料

首页或侧栏打开“数据分析”，选择 `.xlsx`、`.csv` 或 `.tsv` 文件，再点击“读取预览”。选择文件本身不上传。读取时原文件发送到TAgent后端内存，不保存原文件、不调用模型；在远程部署下，这是向部署服务器传输整个文件，不是纯浏览器本地读取。

1. 选择工作表、表头行、末行与首末列，核对实际值。首行必须是非空且唯一的列名，选区至少包含一条数据。
2. 核对单位、公式保存结果、隐藏行列及合并区域，勾选确认后“添加到材料”。修改范围会撤销勾选，追加不覆盖原材料。
3. 继续补充口径与交付要求，预览任务并填入草稿；已有草稿默认保留。只有手动发送才创建任务、保存选择的数据并提交给模型。

读取使用保存值，不重新计算公式。公式没有缓存结果、Excel错误值分别留下明确标记，不转成零；已有缓存也不代表公式结果最新。普通数值保留原始字符串精度；百分比、货币与补零编号的显示格式不自动换算，需核对单位。识别出的日期转为ISO文本，兼容1900/1904日期系统；虚构的1900-02-29拒绝读取。隐藏行列仍包含，合并单元格不向空白传播值；图片、图表、批注不作为数据。

CSV文件使用逗号、TSV使用制表符。默认严格UTF-8；可明确选择中文GB18030/GBK或UTF-16LE，不自动猜编码或以替换字符掩盖乱码。其他分隔符可先另存为逗号CSV，或使用原有文本粘贴入口。旧版`.xls`、加密文件需先另存；含宏、嵌入对象及外部数据连接的工作簿拒绝导入。

单文件最多2 MiB、16个工作表；归档最多256条目、解压总量8 MiB，展开数据区域合计100000个单元格。单表最多5001行（含表头）、64列，单元格2000字符；完整JSON预览上限1 MiB。读取失败或超限不返回截断数据。后端同时读取上限2个，无自动重试。压缩包路径、CRC、XML结构/属性、命名空间与坐标在数据解析前检查，不解压到磁盘、不跟随外部地址。

确认材料包含原文件名/SHA-256、工作表、选区和读取限制，再由CSV编码器保留换行及引号。选中/合并材料最多60 KiB，为完整任务留出空间；最终草稿仍受64 KiB与服务端输入限制。取消或更换文件会中止旧请求，迟到结果不会回填；容量错误不改原材料。关闭窗口和刷新不保留未发送数据，系统不保存可重新下载的原文件；指纹和文本快照不等同原文件档案或真实性证明。

接口为 `POST /api/data/import/preview?name=<文件名>&encoding=utf-8`，请求体是 `application/octet-stream` 原始字节，沿用既有访问控制和正文限制。成功响应为共享 `TableImportPreview`，固定 `requiresConfirmation=true`、`willWrite=false`、`willExecute=false`；这个契约只适用于预览，不代表用户之后发送的材料不进入会话与模型。

## 执行与核对

- `read_data_source` 列出当前任务原文和本任务已选中的完整历史用户消息，按原始物理行读取；不接受文件路径、URL或模型新写的数据。助手回复、摘要、引用摘录与已截断历史不能冒充原始表格。
- `analyze_table` 使用来源编号和含表头的完整行范围。CSV/TSV选区不包含正文说明或代码围栏；Markdown选区必须恰好是一张表。解析失败、重复/空表头、列数不一致和超限都明确拒绝，不跳过坏行或计算截断表格。
- 先检查字段、缺失/非数值及少量样本，再选择统计列。可求和、均值、最小/最大值、非空计数，最多三个分组维度；比较明确指定基期/本期分组与指标，不假设输入顺序等于时间顺序。
- 有效数字用十进制库计算，保留字符串精度，避免 `0.1 + 0.2` 的二进制浮点误差。合法数值不超过40位数字、24位小数；求和/差值/极值/计数在限制内精确，均值及变化率采用 HALF_UP、最多8位小数。
- 空白不替换为零；计数为非空单元格数，而非数值数。数值列含无效值时默认返回不可计算；仅显式选择排除时返回局部统计，并保留缺失、排除数量和异常样本。全部缺失的数值列不产生零合计。
- 不自动识别千分位、货币、百分号或日期，不换算单位，不执行公式。零或负基期不返回普通增长率；均值比较不会用已舍入的均值再计算变化率。
- 回执包含来源原文与所选原文的 SHA-256、行范围、列名、数据行数、指标、比较规则和结果。普通任务及单 Agent 回退均把实际回执作为交付核对材料，同时进入统一 WorkflowEvent 的工具结果，随检查点、会话与历史索引保存。

“工具执行完成”不代表原始数据可信、选区满足业务范围、解释合理或最终报告正确。

## 查看计算记录

回复下方的“表格计算”默认折叠，读取同一任务的实际工具回执，不从模型报告反推数值。可分别展开字段检查和统计结果，查看原文行范围、有效/空白/无效数量、异常样本、基期与本期比较；格式不完整的回执明确提示，不猜测缺失结果。

桌面保留对照表格，窄面板将分组、指标、结果和数据范围纵向排布。长名称默认紧凑展示，展开可查看全文；20组之后按需加载，最多保留工具返回的100组。结果不可计算、部分数据和缺失值在表格前提示，不藏在横向滚动区。原始数据样本仍可横向滚动，不改变原始列顺序。

“核对原文”只在当前会话保留了对应完整用户消息时出现。浏览器用 SHA-256 核对原文及所选行范围，匹配后展示确切原表；原文变化、缺失、选区不一致或浏览器不支持时，不标记为匹配。操作不发送网络/模型请求，指纹一致也不代表数据来源或业务结论已经核实。

历史“执行记录”中的表格工具事件复用同一展示，并保留可展开的原始事件数据。该入口没有加载原文时不提供原文核对。回执随会话刷新恢复，未保存的记录保留警告；查看、展开和加载更多不会重跑任务。

## 下载 Excel

展开一条计算记录后，点击“下载 Excel”。文件在浏览器本地生成，不重新请求模型、重跑工具或保存配置。按钮在生成期间禁用；失败显示原因，由用户点击重试。页面只确认已交给浏览器下载，不把它当作后端保存成功。

- 统计回执导出全部分组和指标，不受页面20组分页限制；包含统计结果、已有的基期/本期比较、异常样本和计算说明。各分组维度独立成列，不拼接或重排名称。
- 字段检查导出字段计数、明确标注的前5条样本和计算说明，不冒充完整原始数据集。
- 普通结果写为可继续计算的 Excel 数值；超过15位有效数字或不能无损往返的结果按文本保留，并标注单元格类型。缺失或不可计算显示“未计算”，不改成零；变化率列的100代表100%。
- 分组、列名和样本文本不执行公式，不附宏、自动链接或外部数据连接。文件保留实际事件/run编号、原文范围、指纹和限制，不包含完整对话、原始数据文件或模型报告。
- 下载的是单次工具记录的静态快照，不是可自动复算的业务模型，也不证明整项任务已完成。运行中或尚未确认保存时，计算说明保留对应状态。历史事件下载使用实际事件标识，不新造一个任务编号。

## 安全与限制

- 工具仅计算本任务已有文本，不读取磁盘、不访问网络、不安装包、不运行任意代码。它们仍受工具白名单控制；`suggest` 需要逐次确认，`auto_edit` 按受信内置本地只读工具处理。
- “本地计算”不是“整个任务不外发”：用户材料及工具结果仍进入用户启动的模型任务，遵守现有模型外发范围。后台不自动触发计算或 Benchmark。
- 单来源上限64 KiB、5000条数据、64列、单元格2000字符；最多100组、8个统计指标、48 KiB回执。超出就拒绝，不给截断合计。读取预览分页，样本明确标注前5条/单元格最多160字符，实际计算使用完整选中数据。
- 尚不包含通用附件存储、Word/PDF读取、自动图表、完整报告/原始文件导出、透视表编辑器、数据库访问、复杂统计建模或跨会话数据检索。原文选区、指标口径和业务解读仍需真实模型与用户任务验收。

XLSX读取使用 [read-excel-file](https://github.com/catamphetamine/read-excel-file) 9.3.10；XML预校验使用 [saxen](https://github.com/nikku/saxen) 11.1.1，CSV材料编码使用 [csv-stringify](https://csv.js.org/stringify/api/sync/) 6.8.3。日期基准参考 [Excel日期系统](https://support.microsoft.com/en-us/excel/date-systems-in-excel)，CRC使用Node22.13已具备的 [zlib.crc32](https://nodejs.org/api/zlib.html#zlibcrc32data-value)。这些检查不是独立安全审计或操作系统沙箱。
