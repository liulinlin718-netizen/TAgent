### 原文约束、修订与任务范围核对

- 原始引用现在可被 `web_research` 定向读取，优先不同站点，每次最多追加 2 个引用，读取总尝试数不超过 8，不递归爬取；来源仍受公网与域名白名单检查。`discoveredFrom` 随重复读取保留。单元测试已验证真实工具流程中的选择、读取、上限和拦截；完整实测未证明所有重要公告都能被自动发现。
- 保留相邻句子的连续原文段落，避免短否定句被过滤；每来源最多 12 段、总计 6000 字符。报告以 `sourceId + passageIndex` 引用明确编号的原文，服务端复制原文，不让模型拼接长引文。旧式 `quote` 输入仍需逐字匹配连续段落。
- `ResearchAssessment.status=sufficient_evidence` 仅是材料可用性，不是事实通过。站点数使用公共后缀识别，但不同站点不必然代表不同新闻来源；正文互引、共同原始引用和同站材料不能自动标为独立互证。

- 综合输出后，工具禁用的模型核对只读取每条结论实际引用的段落，不用其他段落或引用链接的上下文替它补证。需要修订时最多再生成一次、再核对一次；有价格与剩余预算检查，模型网络错误不会自动触发此修订。格式不完整的已完成草稿可修订一次，失败原稿最多保留 32000 字符供私有审计，不作为已确认事实展示。

### 受控子 Agent 执行与历史（2026-09-12）

- `SubTask.spawn` 只接受名称、原因和当前计划中的父任务标识，不能由模型注入工具权限、确认或预算。初始计划驱动最多两层分工；文档等父 Agent 原配置只有一层时仍保持一层。依赖完成后才执行下一层，禁止使用其他运行的任务 Agent 作为父级。需要用户审批的父 Agent 不自动创建子任务，目前没有规划中途审批后自动续跑。
- 创建前继承 Soul、Skills/MCP、工具/域名白名单及治理规则，子预算不超过父预算一半和当前运行分配额度；叶节点可以执行，但不能再创建下一层。现有模型费用仍是收到响应后的本地计量，并非供应商计费硬上限；跨并行/跨进程预算预留和 Loop 内按需递归仍是开放项，不能将初始计划树等同完整自主递归能力。
- `TaskAgentStore` 使用独立 `task-agents` 快照保存来源、冻结的执行配置、状态、完整输出与已知用量。创建与终态均先提交再发布；保存失败不发布伪成功，已返回草稿仍保留在会话结果。已结束记录不允许重开或改写来源。重启只将正在执行的记录标为中断，未执行记录保持未执行，不重跑模型或工具；完整输出保存前的进程故障仍可能留下材料缺口。
- 手动创建接口验证参数与真实会话/运行归属，拒绝权限提升、假来源、未确认创建、无预算和深度耗尽；它只创建未执行记录，不触发模型。晋升预览不创建常驻 Agent，确认后产生独立副本；晋升关联从已提交的常驻记录恢复，避免依赖第二次非原子写入。旧内存记录无法凭空恢复，删除会话后的独立任务历史保留策略仍待产品化。
